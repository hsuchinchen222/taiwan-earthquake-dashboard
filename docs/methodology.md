# 分析方法與解讀範圍

## 來源資料

public/data/taiwan_major_felt_earthquakes_2024-09-25_to_2026-09-25.csv，檔名標示的分析期間為 2024/09/25–2026/09/25。CSV 內 39 筆事件列的實際日期為 2024/10/16–2026/09/22。前端讀取 CSV 後驗證必要欄位、時間格式、數值與唯一報告編號；欄位不完整時顯示錯誤狀態，不會以預設或示意資料補上。

## 指標

1. **總事件數**：目前符合篩選條件的 CSV 列數。
2. **最大規模與最大震度**：分別取 規模_ML 最大值、最大震度序位_分析用 最大值；震度文字直接取該列的 最大震度。
3. **每月事件數**：按 發震時間_TST 的年月分組，並補上觀察月份內的 0 筆月份。
4. **區域分布**：以兩事件間 Haversine 距離不超過 50 公里建立連通元件。連通性具有傳遞性，所以群聚兩端的直線距離可能超過 50 公里。群聚中心用於將元件歸入東部帶、嘉義－臺南帶、宜蘭／東北部或孤立事件。
5. **規模與深度**：在目前樣本上計算 Pearson r；散點圖的虛線為同一批資料的最小平方法線。
6. **規模與震度**：先依 最大震度序位_分析用 對震度排序，再計算規模與震度序位的 Spearman ρ；相同序位使用平均名次。

## 目前來源資料的基準結果

- 39 筆事件；最大規模 M7.0；最大震度 6弱。
- 月份高峰為 2025/01，共 7 筆。
- 50 公里連通元件筆數為 19、13、5、1、1；兩個單筆元件併入「其他／孤立事件」，呈現為 19、13、5、2。
- 最大深度為 113.9 km。散點圖依目前 CSV 的最大深度動態設定座標軸，不固定沿用視覺稿上的 250 km 刻度上限。
- 規模與深度 Pearson r 約 0.446；規模與最大震度序位 Spearman ρ 約 0.156。

## 限制

這是經選樣整理的主要有感事件樣本，不是完整地震目錄；樣本選取會影響月份分布、區域比例與相關係數。50 公里連通群聚是探索性視覺分組，區域名稱是便於一般讀者理解的分類，不能視為地質分區。相關係數不證明因果，也不是地震預測或個人震度預報。
